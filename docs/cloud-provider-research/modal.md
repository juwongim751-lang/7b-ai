# Modal GPU 무료 사용 및 학습 적합성

**확인 기준일: 2026-11-05**

## 결론: 무료 GPU인가?

Modal Starter는 월 $0(컴퓨트 사용료 별도)이며 매월 $30의 무료 컴퓨트 크레딧을 포함한다. 이는 일회성 체험 크레딧이 아니라 Starter 요금제에 월 단위로 표시된 반복 크레딧이다. 다만 GPU는 초당 과금되는 유료 자원이고, GPU를 쓰려면 계정에 유효한 결제수단을 등록해야 한다. 따라서 **결제수단 없이 쓰는 무조건적 무료 GPU는 아니며, 매월 $30까지의 컴퓨트 비용을 상쇄하는 무료 사용분이 있는 형태**다. 요금제는 Starter에서 동시 GPU 최대 10개를 표기하지만, 이는 동시성 한도이지 GPU 용량을 항상 확보한다는 보장은 아니다. [1] [2]

## 크레딧과 비용

가격 페이지는 Starter 포함 컴퓨트를 `$30 / month`로 표시하고, Modal의 모든 워크스페이스가 월별로 청구된다고 설명한다. 미사용 크레딧의 이월 여부나 월별 크레딧이 갱신되는 정확한 날짜·시점은 확인한 공식 페이지에서 설명을 찾지 못했다. 크레딧을 넘는 사용량의 청구가 발생할 수 있으며, Modal은 일정 사용량 기준을 처음 초과할 때 월중 추가 청구한다고 안내한다. [1] [3]

가격 페이지에 표시된 GPU 단가는 T4 $0.000164/초, L4 $0.000222/초, A10 $0.000306/초, L40S $0.000542/초, A100 40GB $0.000583/초, A100 80GB $0.000694/초, RTX PRO 6000 $0.000842/초, H100 SXM5 $0.001097/초, H200 SXM $0.001261/초, B200 $0.001736/초, B300 $0.001972/초다. 가령 크레딧 $30 전부를 GPU 사용료만으로 쓴다고 가정하면 T4 약 50.8 GPU시간, A100 80GB 약 12.0시간, H100 약 7.6시간에 해당한다. 이는 GPU 단가만으로 나눈 이론값이며 CPU·메모리 등 추가 컴퓨트 비용은 제외했다. [1]

## GPU 선택과 실행 제한

GPU 문서는 T4, L4, A10, L40S, A100(40/80GB), RTX PRO 6000, H100, H200, B200, B300 선택을 열거한다. 여러 GPU를 한 컨테이너에 연결할 수 있으며, B300·B200·H200·H100·A100·L4·T4·L40S는 컨테이너당 최대 8개, A10은 최대 4개를 지원한다고 안내한다. 2개 초과 GPU 요청은 대기 시간이 길어질 수 있다. 현재 멀티 GPU 학습은 단일 노드에서 지원하고, 멀티 노드 학습은 문서상 비공개 베타다. [2]

Modal Function의 기본 실행 타임아웃은 5분이며, 사용자가 설정할 수 있는 최대 실행 시간은 실행 시도당 24시간이다. 이 타임아웃은 코드 실행 시간 기준이다. Starter 플랜 가격표는 GPU 동시성 10개를 포함하며, 전체 동시 컨테이너 한도는 플랜에 따라 다르다. [1] [4] [8]

## 계정·결제 조건

계정이 필요하며, GPU 사용에는 유효한 결제수단이 등록되어 있어야 한다. Modal 워크스페이스 안내는 신규 가입 계정의 검증 및 팀원 초대에 결제수단 등록이 필요하다고 명시한다. 문서는 결제수단이라고만 하며, 반드시 신용카드여야 하는지 또는 가입 시 전화번호가 필수인지 확인한 공식 페이지에서는 찾지 못했다. 실제 계정의 결제수단 상태나 남은 크레딧은 이 조사로 확인할 수 없다. [2] [3] [5]

## 저장과 결과물 보존

Modal Volumes는 이름을 가진 영구 저장 볼륨으로 문서화되어 있고, 모델 가중치와 체크포인트 저장에 사용할 수 있다. 컨테이너가 실행 중일 때 수 초마다 백그라운드 커밋을 수행하고 종료 시 최종 스냅샷과 커밋도 수행한다. 외부 컨테이너에서 생성된 최신 변경은 기존 컨테이너에서 `reload()`해야 볼 수 있다. 그러므로 학습 결과와 체크포인트는 Volume에 기록하는 것이 공식 장시간 학습 예시의 방식이다. [6] [7]

컨테이너 로컬 SSD는 기본 쓰기 할당량 512 GiB이며 `ephemeral_disk`는 최대 3 TiB까지 요청할 수 있다. 이 디스크가 컨테이너 종료 뒤 보존된다고 문서는 보장하지 않으므로 영구 결과 저장소로 간주하지 말고, 영속 데이터에는 Volume을 사용해야 한다. Volume 저장 비용은 $0.09/GiB/월이며 가격 페이지는 월 1 TiB 무료분을 표기한다. [1] [7]

## 장시간 사전학습 적합성

Modal은 **장시간 학습을 지원하지만, 24시간을 초과하는 하나의 끊김 없는 Function 호출은 지원하지 않는다.** 공식 예시는 주기적으로 Volume에 체크포인트를 저장하고 재시작 때 최신 체크포인트에서 재개하며, 재시도와 최대 24시간 타임아웃을 설정하는 패턴을 안내한다. 따라서 중단·재개를 고려해 코드를 설계하면 긴 학습 잡을 돌릴 수 있다. [4] [6]

다만 Starter의 $30 크레딧은 장시간 GPU 사전학습을 무상으로 지속하기에는 작다. 공식 가격표의 GPU 단가만 보아도 해당 크레딧은 H100 기준 약 7.6시간 분량이며, CPU·메모리 비용은 별도다. 대규모 또는 장기 사전학습을 실제로 할 수 있는지는 필요한 GPU·동시성·예산·계정별 할당에 좌우된다. Modal이 재개형 장시간 학습 패턴을 문서화한 사실과, 특정 사용자의 장기 학습에 충분한 무료 자원이 배정되어 있다는 주장은 구분해야 한다. [1] [6]

## 미확인 및 계정별 항목

- 무료 크레딧의 미사용분 이월, 만료 규칙, 월별 갱신의 정확한 시점은 확인한 공식 가격·청구 문서에서 찾지 못했다.
- 전화번호 필수 여부와 결제수단이 신용카드로 한정되는지는 확인한 공식 페이지에 명시되어 있지 않다.
- 현재 계정의 잔액, 크레딧 잔여량, 결제수단 등록 여부, GPU 할당·실제 가용성 및 특정 GPU를 즉시 받을 수 있는지는 알 수 없다.
