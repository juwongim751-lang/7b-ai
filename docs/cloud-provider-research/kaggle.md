# Kaggle Notebooks: 무료 GPU 및 런타임 조사

**확인일:** 2026-11-05  
**범위:** Kaggle Notebooks 한 곳. 공식 Kaggle 문서와 Kaggle Staff 답변을 확인했다.

## 결론

Kaggle 공식 문서는 Notebook GPU를 무료라고 명시하며, GPU 사용량은 일회성 체험 크레딧이 아니라 주 단위로 초기화되는 반복 쿼터라고 안내한다. 문서의 기준치는 주 30시간이며, 수요와 자원 상황에 따라 더 높을 수 있다. GPU 용량은 혼잡 시 대기열에 들어갈 수 있어 항상 즉시 할당된다고 보장하지 않는다. [1] [2]

## 가격·쿼터

Notebook 문서는 단일 NVIDIA Tesla P100을 무료로 추가할 수 있다고 명시한다. GPU 사용량 안내는 주간 쿼터가 매주 초기화되고, 30시간 또는 자원·수요에 따라 그보다 많을 수 있다고 설명한다. 따라서 공식 안내상 기본 혜택은 반복되는 무료 주간 사용량이지, 한 번 소진되는 체험 크레딧이 아니다. 다만 문서는 초기화의 요일·시각, 모든 계정에 보장되는 고정 쿼터, 남은 시간의 이월 여부를 명시하지 않는다. [1] [2]

공식 하드웨어 표에는 P100 1개 구성과 T4 2개 구성 모두 기재되어 있다. 하지만 문서가 무료라고 분명히 표현하는 것은 단일 P100이다. T4 2개 구성이 모든 계정에 무료로 제공되는지 또는 해당 계정에서 선택 가능한지는 문서만으로 확인되지 않으므로, 이를 기본 무료 옵션으로 간주하지 않는다. [1]

Notebook 문서는 Colab Pro/Pro+ 가입 계정을 연결할 때 각각 주 15/30시간 추가 GPU 시간을 제공하는 실험적 프로모션도 설명한다. 해당 문서 자체가 이를 제한된 기간의 실험으로 표시하고 변경·종료 권리를 명시하므로, 별도의 확정 Kaggle 요금제나 현재 이용 가능 혜택으로 단정할 수 없다. Notebook 사용량의 별도 가격표나 Kaggle 전용 유료 플랜 정보는 확인하지 못했다. [1]

## GPU·세션 제한

공식 기술 사양에 적힌 GPU 구성은 NVIDIA Tesla P100 1개 또는 NVIDIA Tesla T4 2개이며, 두 구성 모두 4개 CPU 코어와 29GB RAM으로 기재되어 있다. 무료 GPU 추가 설명은 P100 1개를 특정한다. 실제 계정의 선택지와 할당 장치는 계정 설정 및 당시 가용량을 확인해야 한다. [1]

각 CPU/GPU Notebook 편집 세션의 실행 한도는 12시간이다. `Save & Run All`로 버전을 실행할 때도 전체 Notebook이 12시간 안에 끝나야 한다. TPU 세션은 별도 문서상 최대 9시간이다. [1] [3]

유휴 세션 종료 시간에는 공식 문서 간 차이가 있다. Notebook 기술 사양은 20분 동안 코드를 수정하거나 실행하지 않으면 대화형 세션이 끝난다고 적는다. GPU 사용 팁 문서는 대화형 세션이 60분 유휴 타임아웃까지 유지된다고 적는다. 어느 시간이 현재 GPU 세션에 적용되는지 문서만으로 해소되지 않으므로, 보고서에서는 이 유휴 제한을 단일 확정값으로 취급하지 않는다. [1] [2]

무료 GPU 가용량은 제한되며, 혼잡 시 큐 대기가 발생할 수 있다. GPU 안내 페이지는 사용량 확인 위치를 계정 설정·Notebook 화면 등으로 소개하지만, 이 조사에서는 특정 계정의 현재 잔여량이나 할당 상태를 확인하지 않았다. [1] [2]

## 가입·결제 요건

Kaggle Staff가 답변한 공식 제품 피드백 글은 GPU 또는 TPU 사용을 위해 계정 전화번호 인증이 필요하다고 안내한다. 이 답변은 과거 게시물이므로, 현행 Notebook 본문에서 같은 조건이 다시 확인되는지는 찾지 못했다. 카드 등록이 필요한지, 가입 시 결제수단을 요구하는지는 확인한 공식 문서에서 명시를 찾지 못했다. 따라서 카드가 불필요하다고 단정하지 않는다. [4]

## 저장·출력 지속성

Notebook의 `/kaggle/working`에는 최대 20GB의 출력이 자동 저장되며, 이후 Notebook에서 입력 데이터로 다시 사용할 수 있다고 공식 문서는 설명한다. 이 경로 밖의 추가 scratchpad 공간은 현재 세션 밖으로 저장되지 않는다. 따라서 학습 체크포인트는 세션 로컬 임시공간에만 두지 말고 자동 저장되는 출력에 포함되도록 설계하는 편이 문서화된 지속성 모델에 맞는다. [1]

## 장시간 사전학습 적합성

Kaggle Notebooks는 단일 연속 실행이 최대 12시간이고, 무료 GPU 쿼터도 주 단위로 제한되며, 혼잡 시 GPU 큐가 발생할 수 있다. 그러므로 단일 장시간 무중단 사전학습을 보장하거나 장시간 상시 실행 서비스로 쓰기에는 적합하지 않다. 저장 가능한 체크포인트를 만들고 세션을 나눠 재개하는 짧은 학습에는 활용할 수 있지만, 반복 재개가 보장되는 운영 방식이나 계정별 지속 가용성은 공식 문서가 보장하지 않는다. 이는 문서화된 실행·쿼터·저장 한도에 근거한 엔지니어링 판단이다. [1] [2]

## 확인되지 않았거나 계정별인 사항

- 현재 사용자의 GPU 잔여 쿼터, 쿼터 부여량, 리셋 시점과 사용 이력은 계정별이며 확인하지 않았다.
- 현재 GPU/T4 옵션의 노출 여부, 큐 대기시간, 실제 GPU 할당 및 가용성은 계정·시점별이다.
- 계정의 전화 인증 완료 상태, 결제카드 등록 상태 및 특정 계정의 결제 필요 여부는 확인하지 않았다.
- 별도 Kaggle Notebook 가격표/유료 플랜, 카드 요건, 무료 쿼터의 이월 여부와 정확한 주간 리셋 요일·시각은 공식 자료에서 확인하지 못했다.
- Notebook 기술 사양의 20분 유휴 제한과 GPU 팁의 60분 유휴 제한은 공식 문서끼리 일치하지 않는다.
